# Security Policy

## Repository boundary

JobRadar is a job-offer ingestion and ranking example. The public repository
contains source code, synthetic fixtures, and non-secret example configuration
only. Runtime databases, cookies, API credentials, candidate data, and local
profile files must remain outside Git.

## Reporting a vulnerability

Please report security issues privately through the contact details on
[vacaro.es](https://vacaro.es), rather than opening a public issue. Include the
affected component, impact, and reproduction steps without sharing private
candidate or employer data.

Do not crawl sources aggressively or test third-party systems without their
authorization. Respect each source's terms and rate limits.

## Supported releases

Only the latest `main` revision is maintained for this portfolio project.
