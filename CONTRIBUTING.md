# Contributing

- Keep credentials, cookies, personal profiles, candidate data, employer data,
  `.env` files, and generated exports out of the repository.
- Use synthetic fixtures for tests and examples.
- Respect source terms, robots policies, rate limits, and access controls.
- Run `ruff check .`, `mypy app tests`, and `pytest` before opening a change.

Describe behavioral, operational, and privacy implications in pull requests.
